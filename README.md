# 公考资讯日报

每天一期，汇总公安联考、国考、省考（含社会招警）的**官方**公告与关键时间节点。
按《公安联考与公务员考试资讯日报_模板与采集清单》的 8 个固定板块制作。

- 线上：https://lilithwang008.github.io/gongkao-daily/
- 仓库：`Lilithwang008/gongkao-daily`（public，main 分支根目录）
- 自动出刊：每天 08:00，与 07:30 资讯雷达、08:30 AI 日报错开

## 三条铁律

1. **只发原文**：进「今日新公告」的每条都要能点开官方页面，附发布单位、发布时间、涉及对象、状态。
2. **传闻单列**：网传、培训机构说法一律放 08「明日预告与待确认」，标【网传·待证】，不写成事实。
3. **赛道必标**：公安联考 / 国考 / 省考·社会招警 / 通用，四条赛道分开。省考公安岗是**社会招警**，不等于公安联考。

## 目录

| 文件 | 作用 |
|---|---|
| `index.html` | 首页，永远是最新一期 |
| `archive/YYYY-MM-DD.html` | 每一期的独立归档页，首页与归档页可互相跳转 |
| `data/day-YYYY-MM-DD.json` | 一期的全部内容，一天一个文件 |
| `data/day.template.json` | 新一期字段模板 |
| `assets/skeleton.html` | 站点骨架快照（本地用，不上线） |
| `build.py` | 扫描 `data/`，重建首页与全部归档页 |
| `check.py` | 发布前自检 |
| `publish.py` | 走 GitHub REST API 发布 |

## 出一期（自动化每天执行的就是这几步）

1. 看最近 3 期 `data/day-*.json` 的标题与原文链接做去重。
2. 按采集清单检索官方信源，写 `data/day-YYYY-MM-DD.json`（字段见模板）。
   **即使当天没有新公告也要出一期**：01 板块写「今日无官方新公告」，02 更新倒计时，08 写待确认。
3. `python build.py` — 自动算期号、重建首页与每期归档页，历史期数不丢。
4. `python check.py` — 字段、字数、赛道、官方链接、归档页、内联 JS 语法，全部 PASS 才能发。
5. `python publish.py "YYYY-MM-DD 日报更新"` — 禁止 `git push`（本机代理只放行 `api.github.com`）。
6. 等 10–60 秒确认线上 200 且报头日期为当天。

## 页面能力

暖色手绘 ↔ 冷色科技双主题（记住选择）、点开看详情、100 字内速览、阅读记录单条删除/清空、
赛道筛选、往期切换、手机端自适应。阅读记录只存在本机浏览器 localStorage，站点不采集任何数据。

考试信息一律以官方公告与本人准考证为准。
